# «Школа английского языка» — Конституция проекта

## Core Principles

### I. Spec-First Development
Каждая фича/модуль начинается со спеки в `specs/NNN-<slug>/`: `spec.md` → `plan.md` → `tasks.md` → реализация. Код без спеки не пишется. Спеки генерируются и обновляются через Spec Kit скиллы (`/speckit-*`), а не вручную-наполовину.

### II. Module Isolation
Один модуль = одна папка `src/modules/<name>/` со своими страницами, компонентами и данными. Модули не импортируют друг друга; общий код выносится в `src/components/`, `src/data/`, `src/store/`. Удаление модуля не должно ломать остальные.

### III. Frontend-Only (NON-NEGOTIABLE)
Бэкенда нет и не будет. Запрещены: серверный код, API-запросы к внешним сервисам данных, переменные окружения с секретами. Все данные — локальные JSON в `src/data/` и/или `localStorage` браузера через zustand persist.

### IV. Fixed Stack
Технологии фиксированы в `AGENTS.md` и `requirements.txt`: React 19 + JSX (без TypeScript), Vite, Tailwind CSS v4, react-router-dom, zustand, react-big-calendar, recharts, lucide-react, date-fns. Новые зависимости — только по явной необходимости из спеки и с согласованием.

### V. Small Pages, Small Modules
Сайт — набор небольших страниц и модулей, а не монолит. Одна спека = одна публичная страница или один законченный виджет расписания/графика. Спеки остаются маленькими; большая фича дробится на несколько спек.

## Constraints

- Язык интерфейса и контента: русский; домен — школа английского языка.
- Данные правдоподобные, но вымышленные (фиктивные студенты, группы, расписание).
- Каждый модуль должен работать при запуске `npm run dev` без дополнительной настройки.
- Вся команда работает на Windows: скрипты spec-kit — PowerShell (`.ps1`), команды в README покрывают Git Bash и PowerShell.

## Development Workflow

- Порядок скиллов на фичу: `/speckit-specify` → (опц. `/speckit-clarify`) → `/speckit-plan` → `/speckit-tasks` → (опц. `/speckit-analyze`) → `/speckit-implement` → `/speckit-converge` до `Converged`.
- Ревью каждого артефакта до перехода к следующему шагу — спека и план правятся вручную при необходимости.
- Коммиты атомарные, по модулю/этапу; `.devin/` не коммитится.

## Governance

Конституция важнее отдельных инструкций. Изменения оформляются правкой этого файла (с датой в подвале) и синхронизацией `AGENTS.md`/`README.md`. Детали повседневной работы агента — в `AGENTS.md`.
