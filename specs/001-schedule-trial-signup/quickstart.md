# Quickstart: проверка фичи «Расписание + пробный урок»

## Подготовка

```bash
npm install        # или: npm install $(grep -v '^#' requirements.txt | grep -v '^\s*$' | xargs)
npm run dev        # → http://localhost:5173
```

Открыть `http://localhost:5173/schedule` (или `/` — редирект).

## Сценарии проверки (соответствуют acceptance criteria спеки)

| # | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть `/schedule` | Недельная сетка, все 6 групп: уровень, преподаватель, дни, время, «N из 8» |
| 2 | Найти группу Foundation (g2, enrolled=8) | На событиях «мест нет», запись недоступна |
| 3 | Кликнуть занятие свободной группы → «Записаться на пробный» | Форма: дата (ближайшие занятия), имя, телефон, email |
| 4 | Отправить форму с пустым именем / «123» | Ошибки у полей на русском, запись не создана |
| 5 | Заполнить имя «Иван», телефон «+7 900 123-45-67», дату → отправить | Подтверждение с группой/датой/временем; счётчик мест у группы −1 |
| 6 | Повторить запись с тем же телефоном на другую группу | Показ «у вас уже есть запись» → «Перезаписаться» → старая отменена, новая активна |
| 7 | Перезагрузить страницу | Блок «Вы записаны на пробный урок» с деталями |
| 8 | Нажать «Отменить запись» | Блок исчез, место вернулось группе |
| 9 | Сузить окно до ~360px | Расписание читаемо, горизонтальный скролл/адаптация, без сломанной вёрстки |

## Быстрая проверка логики (DevTools Console)

```js
JSON.parse(localStorage.getItem('trial-bookings'))  // состояние записей
localStorage.removeItem('trial-bookings')            // сброс для чистого прогона
```
