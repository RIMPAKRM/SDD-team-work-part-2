# Quickstart: проверка фичи «Тест на уровень»

## Подготовка

```bash
npm install
npm run dev        # → http://localhost:5173
```

Открыть `http://localhost:5173/test`.

## Сценарии проверки (соответствуют acceptance criteria спеки)

| # | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть `/test` | Экран приветствия с кнопкой «Пройти тест» (или сохранённый результат, если тест уже пройден) |
| 2 | Начать тест | Вопрос 1 из 15, 4 варианта ответа, прогресс «Вопрос 1 из 15» |
| 3 | Попробовать «Далее» без выбора ответа | Переход заблокирован |
| 4 | Выбрать ответ → «Далее» → «Назад» | Следующий вопрос; при возврате предыдущий ответ сохранён |
| 5 | Ответить на все 15 → «Узнать результат» | Уровень (один из четырёх) + «X из 15» + описание |
| 6 | Проверить рекомендацию | Показана группа уровня результата (Beginner→group-1/A1 и т.д.) с преподавателем и расписанием |
| 7 | Нажать «Записаться на пробный» | Переход на `/?group=<id>` — открывается страница расписания (подсветка группы — когда 001 её поддержит) |
| 8 | Перезагрузить `/test` | Сохранённый результат на месте + кнопка «Пройти заново» |
| 9 | «Пройти заново» → завершить с другими ответами | Результат обновлён новым |
| 10 | Сузить окно до ~360px | Вопросы/варианты/результат читаемы, вёрстка цела |

## Проверка уровней по счёту

Чтобы получить конкретный уровень: ответить правильно на 0–4 → Beginner; 5–8 → Elementary; 9–12 → Intermediate; 13–15 → Upper-Intermediate. Вариант быстрого прогона: `localStorage.removeItem('test-result')` — сброс результата.

## Проверка «мест нет» в рекомендации

Штатной занятости (`enrolled`) в данных нет — «мест нет» наступает при 8 активных пробных записях на каждое ближайшее занятие группы. Чтобы проверить: через DevTools Console добавить 8 записей в `localStorage['trial_signups']` на ближайшие слоты `group-2` (Вт и Пт 19:00, ближайшие даты) → получить уровень Elementary → рекомендация `group-2` помечена «мест нет», показаны альтернативы (`group-1`/`group-3`).
